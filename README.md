
# LifeXP 🚀

this is a gamified web application where users complete challenges to earn XP (experience points). As users gain XP, their profile level and rank increase — making self-improvement feel like a game.

## ✨ Features
- User signup and login (frontend only)
- Multiple types of challenges
- XP system with levels and ranks
- User profile with progress tracking
- Clean light-mode UI (dark mode planned)

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)

## 📌 Current Status
- Frontend only
- Challenges stored in arrays (no backend yet)
- Authentication simulated on client side

## 🔮 Future Plans
- Backend integration
- Database for users & challenges
- Secure authentication
- Dark / Night mode
- More challenge categories

## 🎯 Purpose
This project is built for learning and practicing:
- JavaScript logic
- State management
- Auth flow concepts
- Gamification systems
